Pipeline

A closed-loop adversarial audit

Each phase transforms the output of the previous one. The model is the only input. A full audit report is the only output.

Phase 1 + 2

Attack Surface

Any PyTorch model plugs in through a three-method abstract base class: predict(), get_gradients(), get_activations(). Captum Integrated Gradients and Saliency compute per-layer vulnerability scores — a weighted combination of gradient norm and activation entropy — producing a ranked attack priority list that directs Phase 3 precisely where the model is most exposed.

BaseModel ABC Captum IntegratedGradients Saliency Gradient Norm Activation Entropy
Phase 3

Attack Engine

FGSM and PGD are implemented from scratch using PyTorch autograd — no Cleverhans, no ART. Adversarial patches follow Brown et al. (2017): a fixed-size optimized patch is placement-invariant and physically realizable. Semantic attacks (brightness, contrast, rotation, color jitter) probe invariance failures beyond additive perturbations. Every successful attack yields an AdversarialExample dataclass carrying full provenance metadata.

FGSM PGD Adversarial Patch Brown et al. 2017 Semantic Perturbation
Phase 4

Clustering

Penultimate-layer activations encode why the model was fooled, not just that it was. UMAP reduces these high-dimensional vectors to 2D via non-linear manifold approximation — n_neighbors adapts to sample count to avoid degenerate embeddings. HDBSCAN discovers cluster count automatically and labels noise as -1. PCA serves as fallback for small N. The output is a VulnerabilityTaxonomy: a data-driven map of the model's failure modes.

UMAP HDBSCAN Adaptive n_neighbors PCA Fallback VulnerabilityTaxonomy
Phase 5

LLM Agent

A LangGraph stateful agent retrieves the top-k relevant chunks from a FAISS index of 10 adversarial ML papers using nomic-embed-text dense embeddings. Cluster statistics, member attack types, and retrieved chunks are injected into a structured prompt. Gemini 2.5 Flash generates a grounded technical explanation and targeted patch strategy per cluster — citations included, hallucinations structurally constrained by retrieval grounding.

LangGraph FAISS RAG nomic-embed-text Gemini 2.5 Flash 10 Papers
Phase 6

Patching

Four strategies — adversarial training, stylized augmentation, counterfactual generation, targeted augmentation — are executed in order of LLM recommendation. A 3-retry loop escalates strategy on failure. The composite safety gate requires 0.6 × resistance_gain + 0.4 × accuracy_retention ≥ 0.70 AND clean accuracy drop ≤ 3%. Both conditions must hold. The tradeoff between robustness and accuracy is explicit, measured, and auditable.

Adversarial Training Stylized Augmentation Counterfactual Gen 3-Retry Loop Safety Gate 0.70
Phase 7

Audit Report

ReportLab assembles a structured multi-page PDF: cover page, executive summary, matplotlib radar charts (attack-type success rates), per-cluster cards with LLM explanations and patch outcomes, and a methodology appendix. The radar chart gives the model's adversarial profile a visual signature — flat polygon means uniform robustness, spiked polygon reveals asymmetric weaknesses. No template. No human editing. Output is directly shareable.

ReportLab matplotlib Radar Charts Executive Summary Per-Cluster Cards Methodology Appendix
Phase 8

API

FastAPI wraps the pipeline with async job management via BackgroundTasks. POST /audit/upload accepts multipart images and returns a job_id immediately. GET /audit/job/{id} is the polling endpoint. CORS is configured for ganglet.github.io. The application runs in Docker on HuggingFace Spaces with persistent report storage and cold-start wake handling.

Quick Start

Up and running in minutes

CLI bash
$ git clone https://github.com/Ganglet/Anvil.git && cd Anvil_Project
$ python3 -m venv venv && source venv/bin/activate
$ pip install -r requirements.txt
$ export GOOGLE_API_KEY=your_key_here
$ python audit.py --model resnet18 --input ./samples/ --output report.pdf --budget 20
Docker bash
$ echo "GOOGLE_API_KEY=your_key_here" > .env
$ docker-compose up --build
 
# Trigger an audit via the REST API
$ curl -X POST https://angshuman12-anvil.hf.space/audit/upload \
       -F "model=resnet18" -F "budget=20" -F "files=@image.jpg"
 
# Poll for completion
$ curl https://angshuman12-anvil.hf.space/audit/job/<job_id>
