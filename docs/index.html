How It Works

A closed-loop audit pipeline

Each phase transforms the output of the previous one. The model is the only input. A complete audit report is the only output.

Phase 1

Model-Agnostic Interface

Any PyTorch model plugs in through a unified ABC exposing predict(), get_gradients(), and get_activations(). Ships with ResNet-18 and DistilBERT wrappers.

BaseModel ABC
Phase 2

Attack Surface Profiler

Computes gradient norms, activation entropy, and Captum saliency per layer. Produces a vulnerability score and ranked attack priority list that guides Phase 3.

Captum · IntegratedGradients
Phase 3

Multi-Strategy Attack Engine

FGSM and PGD implemented from scratch using PyTorch autograd. Adversarial patch and semantic attacks (brightness, contrast, rotation). Text perturbation for NLP models.

FGSM · PGD · Patch · Semantic
Phase 4

Failure Mode Clustering

Extracts penultimate-layer activations from all successful attacks, reduces dimensionality with UMAP, clusters with HDBSCAN. No pre-specified cluster count — the taxonomy emerges from the data.

UMAP · HDBSCAN
Phase 5

LLM Explanation Agent

A LangGraph agent retrieves paper chunks from a FAISS index of 10 adversarial ML papers, then uses Gemini 2.5 Flash to write a grounded technical explanation and patch strategy per cluster.

LangGraph · FAISS RAG · Gemini 2.5
Phase 6

Autonomous Patching

Executes the recommended strategy (adversarial training, stylized augmentation, counterfactual generation, or targeted augmentation) with a 3-retry loop and composite safety gate (score ≥ 0.70).

4 strategies · 3-retry loop
Phase 7

PDF Audit Report

All phase outputs compiled into a professional multi-page PDF — cover page, executive summary, radar charts, per-cluster cards with LLM explanations, patch results, and methodology.

ReportLab · matplotlib
Phase 8

API + Deployment

FastAPI server with POST /audit and GET /report/{"{filename}"} endpoints. Packaged in Docker, deployed on Oracle Cloud Always Free VM.

FastAPI · Docker · Oracle Cloud

Quick Start

Up and running in 3 steps

CLI bash
$ git clone https://github.com/Ganglet/Anvil.git && cd Anvil_Project
$ pip install -r requirements.txt
$ export GOOGLE_API_KEY=your_key_here
$ python audit.py --model resnet18 --input ./samples/ --output report.pdf --budget 20
Docker bash
$ echo "GOOGLE_API_KEY=your_key_here" > .env
$ docker-compose up --build
 
# Trigger an audit via the REST API
$ curl -X POST http://localhost:8000/audit \
          -H "Content-Type: application/json" \
          -d '{"model": "resnet18", "budget": 20}'
